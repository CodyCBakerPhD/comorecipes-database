# CoMo Recipes Database

The collection of recipes for our household.

These are nicely rendered on the main [CoMo Recipes website](https://github.com/CodyCBakerPhD/comorecipes).

- [`recipes/`](recipes/README.md): one YAML file per recipe, and the conventions behind them.
- [`ingredients/`](ingredients/README.md): registered ingredients and their package defaults.
- [`schemas/`](schemas/README.md): what every record is validated against, and how to run the check yourself.
